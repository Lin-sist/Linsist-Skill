# Java Agent / RAG 可选基础切片

这是候选题库，不是统一必修路线，更不是个人项目履历。先从用户自有简历提取机制，再参考 [对齐检查表](alignment-notes.md) 选择一个缺口。没有用户简历时只做通用摸底，不假定其已经实现以下能力。

只有用户真实项目中已经实现，并能提供代码或测试证据的技术成果，才能作为个人项目经历陈述；未在用户工程中落地或缺乏证据支持的技术，只能作为行业通用方案比较，严禁使用『我们实现了/建立了』的确定性第一人称经历表达。

| 编号 | 机制 | 最小练习方向 | 事实边界 |
| --- | --- | --- | --- |
| S01 | Tool Calling 与参数绑定 | 手写一个白名单分发函数 | 只验证类型与参数，不冒充业务授权 |
| S02 | Loop 与状态机 | 手写合法迁移及终态保护 | 状态和枚举来自用户项目，示例不替代事实 |
| S03 | HITL | 手写提议与确认边界 | 区分提议执行和暂停恢复，不预设实现 |
| S04 | Guardrails | 手写一个确定性检查 | 规则无法证明完整安全或语义真实性 |
| S05 | 共享时间预算 | 手写剩余预算判定 | 时间和重试上限取决于真实业务 |
| S06 | 受控 Reflection | 手写白名单触发与次数上限 | 示例错误类型不代表项目触发集合 |
| S07 | Memory 与时间策略 | 手写一个可注入时间的预算纯函数 | 区分元数据召回、时间标签、裁剪和衰减 |
| S08 | 工具权限边界 | 手写未知工具与非法参数拒绝 | Schema、鉴权和副作用许可分别判断 |
| S09 | Tracing | 手写事件元数据白名单 | 普通日志、结构化轨迹和 OTel 并不等同 |
| S10 | Agent Evaluation | 手写离线不变量与通过率 | Fake LLM 回归不证明真实模型质量 |
| S11 | 文档分块 | 手写最小分块边界 | 分块参数是实验假设，不是通用最优值 |
| S12 | 向量索引 | 比较 IVF/HNSW 的召回与代价 | 仅当用户简历涉及时安排，不预设当前索引 |
| S13 | 关键词检索 | 手算或实现一个词频检索切片 | 精确匹配与语义匹配各有局限 |
| S14 | 排名融合 | 手写最小 RRF 计算 | 与校准分数融合比较，不宣称唯一路径 |
| S15 | Reranker | 比较规则与模型重排 | 默认选择及 A/B 指标必须由用户证据确定 |
| S16 | 重排故障降级 | 手写一个显式失败回退分支 | 不承诺示例时延或把降级伪装成完整成功 |
| S17 | 引用校验 | 手算一例交集/片段覆盖度 | 区分重合、Jaccard、语义蕴含与事实正确 |

| S19 | 租户与权限 | 手写可信身份到过滤条件的传递 | 示例条件不替代全路径越权测试 |
| S20 | 检索指标与门禁 | 手算 Recall/Precision/MRR | 样本、分母、版本和真实调用范围分别记录 |

## 指标示例

- **Recall@K**：前 K 个结果中命中的相关文档数 / 该查询真实相关文档总数。
- **Precision@K**：前 K 个结果中相关文档数 / K。
- **MRR (Mean Reciprocal Rank)**：各查询首个相关文档排名倒数的均值，无命中记 0。

这些定义不提供任何人的当前分数或默认样本量。检索质量、生成质量、引用来源和拒答质量需要分开验收。课程不预设已接入 CI、真实 provider 或特定生产平台。
