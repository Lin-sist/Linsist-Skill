# 学习工作区与复测接入

适用于 coach、basics、os、testlab。模拟面试只使用本场材料，不在面试启动时读取学习记录。

## 首次使用

1. 以用户指定的项目或笔记目录为学习根目录；未指定时使用当前工作目录。如果当前目录是技能安装目录或 Linsist 源码目录，先进行本轮对话练习，确定保存位置后再建档，不把个人学习记录写进技能源码。
2. 从实际加载的 `linsist-coach/SKILL.md` 所在目录确定技能根路径，脚本和课程均相对此路径解析。不要假设当前项目下存在 `scripts/` 或 `curriculums/`。
3. 工作区尚未初始化时，用可用的 Python 3 解释器执行以下命令；用真实绝对路径替换占位符，路径包含空格时加引号。macOS/Linux 通常为 `python3`，Windows 可使用 `py -3`。

   ```text
   python3 "<教练技能目录>/scripts/init_workspace.py" --dir "<学习根目录>"
   ```

   初始化不会覆盖已有配置、画像或看板。没有 Python 或终端工具时仍可开展对话练习；有文件写入工具时可按模板建档，并明确未执行脚本扫描，不能虚构运行结果。
4. 读取 `.linsist/config.md` 和画像。笔记、错题、看板路径遵循配置的 `storage.notes_dir`、`mistakes_dir`、`retest_dashboard`，相对路径以学习根目录解析。`learner.profile_path` 指定画像路径。未配置时使用 `.linsist/` 下的默认文件。
5. `active_curriculums` 中的 `java-agent-rag` 指向本技能的 `references/curriculums/java-agent-rag/`；自定义课程路径相对学习根目录解析。课程只是可选题源，没有用户工程源码时不宣称已定位或核验课程里的示例类。

## 开场与收尾

- 开场按 `spaced_retrieval.auto_scan_on_startup` 判断是否自动扫描（默认 true）。使用实际安装脚本的绝对路径：

  ```text
  python3 "<教练技能目录>/scripts/scan_retest.py" --dir "<学习根目录>" --json
  ```

- `--json` 和普通输出默认都会更新完整看板；只读检查使用 `--no-dashboard`。`--stage` 仅筛选输出，不删除另一轮的看板记录。每次最多选择 `max_retest_per_session` 道到期题，逐题提问。
- 笔记是复测状态的来源，看板由扫描器生成。收尾先按本专项记录模板写入笔记的复测区，再扫描刷新看板；复测后修改原始笔记里的复测状态或题目旁的状态标记，再扫描。不要只修改看板，否则下次扫描会覆盖这些改动。
- 日期以用户本地日历填写；扫描器使用运行机器的本地日期，按天判断到期，并非精确到小时的计时器。首轮与二轮日期都应显式写入。未写二轮日期但状态为“第1轮已通过”时，兼容旧卡片：以首轮建议日期加 `interval_hours_tier2`（默认 168 小时，按整天换算）生成二轮日期。
- 两道题可以分别标记 `[第1轮已通过]` 或 `[已完全掌握]`；整卡状态只在所有题均达到相同阶段时更新。练习执行 Passed、费曼验收通过均不代表复测通过。
- 如果用户暂停、结束训练或明确要求直接讲解，遵从其要求，不强制继续闭卷问答。无法写文件时交付可复制的卡片，并说明未保存。
