# 学习者背景配置模板 (Learner Profile Template)

只填写用户主动提供的内容，不从示例补全个人信息。项目存在实现不代表学习者已掌握。画像属于用户本地工作区，不写回开源技能。

## 目标与材料

- **目标岗位**：<用户自己的 Agent 岗位方向；可选 JD>
- **简历或经历摘要来源**：<用户本场提供的文件/文本；可留空，不自动查找私人材料>
- **主要语言与技术栈**：<从简历或本场选择确定，不默认 Java 或特定框架>
- **当前阶段**：<用户自述；未提供则未知>

## 时间与能力

- **本次可用时间**：<由用户给出；未给出时先选一个最小练习>
- **已独立写出的机制**：<题目及真实证据>
- **提示后可完成的机制**：<最高提示级别及卡点>
- **尚待确认的基础**：<根据摸底记录，不按项目成熟度猜测>

## 用户自己的项目与续学

- **项目名称与机制**：<用户自己的项目；没有项目时可只练通用机制>
- **获准查看的代码路径**：<仅在需要核验项目时提供>
- **当前主题与下次第一步**：<一个最小机制，不预设课程包>
- **学习记录位置**：<用户选定的项目或笔记目录；默认沿用 .linsist/>
