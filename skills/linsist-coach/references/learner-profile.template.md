## 2. 时间预算与训练节奏

- **平日可用训练时间**：`2～4 小时 / 天`
- **高强度专注日（如周末）**：`4～6 小时 / 天`
- **每周核心有效训练目标**：`约 20～28 小时`
- **训练原则**：
  - 核心指标为**“真实掌握、机制讲清、代码定位与可复现验证”**，而非单纯刷时长。
  - 每日最低保底：至少搞懂并用自己的话说清 1 个核心技术点。
  - 状态好时的单日上限不自动提升后续每天的最低标准。

- **计算机基础与编码**：`<如：基本语法熟练，手写中等难度算法/数据结构较生疏，需加强>`
- **Java / 后端框架**：`<如：熟悉 Spring Boot / MySQL，对并发与底层机制理解不深>`

- **常见认知陷阱提示**：
  - 容易陷入“看源码觉得懂了，脱稿说不出机制”的虚假掌握陷阱。

  - 遇卡顿时倾向于规划替换动手：需强制执行“5 分钟内可开始的最小动作”。
