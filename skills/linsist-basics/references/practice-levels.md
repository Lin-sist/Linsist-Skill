# 手写任务选题与难度分级 (Practice Levels)

> 本规范指导 `linsist-basics` 为学习者精选 10～30 分钟内可完成的手写代码训练。杜绝盲目硬刷高难度算法，聚焦 Java 后端与工程基础。

---

## 1. 手写训练技能树与当前优先级

### P0：核心高频必刷（重点夯实）
- **字符串与字符处理**：按条件遍历、原地反转、字符词频统计、回文判断。
- **数组与线性结构**：元素原地去重、查找、滑动窗口基础、双指针基础。
- **HashMap / Set 频次统计**：高频词统计、分组聚合、TopK 候选统计。
- **ArrayList / 链表操作**：常见增删改查遍历、反转单链表、合并有序链表。
- **经典算法思想**：二分查找（边界防溢出）、冒泡/选择排序基本思想、简单树遍历。
- **手写 SQL 与聚合**：GROUP BY 分组过滤、多表 JOIN、HAVING 条件、排序分页。

### P1：基础巩固后进阶
- 栈与队列的互相模拟与简单应用（如有效括号匹配）。
- 简单二叉树前中后序遍历及层序遍历。
- LeetCode / Hot100 简单与中等偏易题型。

### 暂缓（现阶段性价比低）
- 复杂动态规划（多维状态转移）。
- 复杂图论算法（网络流、强连通分量）。
- 红黑树底层手写实现。
- JDK / Spring 复杂源码级手写。

---

## 2. 出题与验收要求

出题时必须严格满足以下标准：
1. **与当日所学主题强关联**：如当日学习 HashMap 底层原理，手写题即为基于 HashMap 的统计与分组。
2. **Java 语言完整可运行**：给出清晰的输入格式、输出要求与边界说明。
3. **时间预算**：单题控制在 10～20 分钟内完成，杜绝耗时数小时的庞大任务。
4. **难度自适应**：
   - 题目难度略高于用户当前水平，形成“跳一跳能够得着”的适度挑战。
   - 若用户连续两次任务完成得非常轻松，可顺势提高一个小等级。
   - 若用户在编码中表现出明显吃力或语法生疏，立即降低难度，先练习拆解动作，不强行推进。
5. **渐进提示机制**：
   - 第一次提交前严禁直接提供参考答案代码。
   - 遇阻时依次提供：思路方向提示 -> 核心 API 提示 -> 关键逻辑伪代码。
