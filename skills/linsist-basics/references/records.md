# 基础训练短记录模板 (Basics Practice Record)

> 记录留在用户本地工作区（如 `.linsist/notes/`），不要求长篇大论，突出真实编码用时与独立完成状态。结构化标记仅用于写入文件，不在对话中直接倾倒。

```markdown
# [YYYY-MM-DD] 基础手写与算法训练卡

- **当日核心主题**：<如：HashMap 词频统计与碰撞处理 / 二分查找边界防溢出>
- **摸底自测状态**：独立写出 / 提示后写出 / 仅能理解思路 / 暂未掌握
- **手写任务完成情况**：
  - 任务题目：<题目简述与输入输出>
  - 耗时与独立性：用时 X 分钟 / 独立完成 (或接受过 API 提示)
  - 验证方式：本地运行单元测试通过 / IDE 运行通过 / 口头逻辑推演
- **踩坑点与原始写法偏差**：<记录如边界越界、空指针、未能处理并列最大值等实际 Bug>
- **正确实现核心机制**：<修复后的关键语法与逻辑重点>
- **面试 60 秒技术自述**：<如何用简洁语言向面试官阐释此代码的设计与时空复杂度>
- **48h 闭卷复测设计**：
  - 建议复测日期：`YYYY-MM-DD` (48 小时后)
  - 复测题目 1（概念机制）：<脱稿口述核心语法/机制原理>
  - 复测题目 2（白板手写）：<手写同类变种题或核心代码段>
  - 复测状态：待复测 / 已通过 / 二次巩固
- **下次启动第一步**：<精准到具体代码题目的最小动作>
```
