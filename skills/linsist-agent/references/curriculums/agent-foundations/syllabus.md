# Agent Foundations：简历靶向的基础手写

本课程面向 Agent 岗位，以用户本场提供的简历为边界，结合可选 JD 和摸底决定选题。下面是候选机制及示例优先级；简历未涉及的主题不自动列为必修。所有练习都是独立、内存内、合成数据的教学实验，不代表某位作者或用户的项目实现。

一次只选一行，不依次灌输整张表。起步可选 A01；已会则依据摸底跳到暴露的缺口。Python 语法不足时先用基础技能补一个必要点，不先上框架或真实模型。

| --- | --- | --- | --- | --- |

## 拓展额度

仅在本题验收后，按用户需要拓展一个边界：A08 的“最长未覆盖片段”、A07 的数据库唯一键、A06 的元数据召回、A13 的取消传播。不要一次实现多个机制。

MCP 完整生命周期、LangGraph、MCP Client、多智能体、GraphRAG、沙箱平台与模型微调默认不安排；用户明确提出后才选入。A10 仅是 RPC 层教学子集，不是完整 MCP 实现或兼容性认证。ReAct 讨论可见的动作和观测，不要求输出模型私有思维链。

每题的 [输入输出契约](exercises.md)、[提示规则](../../practice-guide.md)、[复测模板](../../records.md) 按需读取。讲解模板：“是什么 → 当前函数为何需要 → 一个失败边界”，其余时间交给学习者写代码。
