# 手写实践与三级提示

每次只练一个编号。先口头摸底，再给任务契约；不先展示整套脚手架或验收器源码。复制文件不等于提交了独立实现。

## 离线起步

以实际安装的技能目录为基准，复制 `assets/agent_lab.py` 为学习工作区中的 `agent_lab.py`（已有文件则换名，不覆盖）。先执行：

```text
python3 "<学习目录>/agent_lab.py" --smoke
```

该命令只验证标准库 Fake LLM 可以按脚本返回动作与 final，不执行学生的 Loop。无需设置 API Key，也不尝试真实 provider 或自动安装依赖。

选定 A01 后，先讲清契约，学习者实现对应函数，再执行：

```text
python3 "<技能目录>/assets/check_agent_lab.py" --exercise A01 --submission "<学习目录>/agent_lab.py"
```

验收器只检查该编号，不会要求一次完成所有空函数。未实现会明确失败；不得把失败测试跳过后称为通过。Linux 上对可能死循环的提交加 `timeout 5s`，或用 Python `subprocess.run(..., timeout=5)` 限时；超时算失败，不自动修复或重试。提交文件只在获准的学习目录运行。

## 提示层级

| 层级 | 给什么 | 不能给什么 |
| --- | --- | --- |
| 1：方向 | 指出当前要维护的不变量，如“每一次模型请求都消耗一步” | 完整控制流程或成品函数 |
| 2：API/数据结构 | 一个必要结构，如字典白名单、Set、剩余预算，或一个 API 名称 | 把多个提示拼成完整实现 |
| 3：局部伪代码 | 只展示卡住分支的 2～4 行伪代码，如非法参数的提前返回 | 覆盖整个题目的伪代码或可直接运行答案 |

由学习者请求提示或确实卡住后，才给下一层；每轮只给一级。连续两次基础阻塞则缩小任务，例如先只处理 final 停止，再补步数上限。记录最高提示级别，不把提示后完成标为独立完成。学习者提交后也优先报一个反例或失败断言，让其自行修正。

用户明确要求看答案或切换讲解时可遵从，记录为“参考讲解”，之后用变种题重新验证独立性。参考讲解不计独立手写通过。

## 面试收尾

一次只问一个问题，例如“你怎样证明这个循环最多调用 N 次？”或“这个内存幂等标记为什么不能保证服务重启后的幂等？”不要在同一轮追加一串问句。

用“我在独立实验中验证了……”复述实验；只有核验到真实工程证据才映射到项目。运行通过、机制讲清、复测通过是三种不同证据。
