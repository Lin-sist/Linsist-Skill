# Agent 基础手写训练卡

复用 `.linsist/notes/YYYY-MM-DD_agent_<主题>.md`；没有新数据库或新的扫描器。两轮日期使用真实日期分别替换，建议首轮学习后 48h、二轮学习后 168h。原始卡片是状态来源；扫描行为沿用 coach 的工作区指南。

```markdown
# [YYYY-MM-DD] Agent 基础手写训练

- **当日核心主题**：<A01 / 本次一个最小机制>
- **简历靶点与材料版本**：<本场简历的机制；不复制身份信息>
- **知识与证据类别**：通用 Agent 知识 / 独立实验 / 已核验项目证据
- **摸底与认知偏差**：<初次回答、纠正点>
- **手写契约**：<函数签名、输入、输出与边界>
- **完成独立性**：独立完成 / 提示后完成 / 参考讲解
- **最高提示级别**：0 / 1 / 2 / 3
- **实际执行证据**：<提交文件、运行命令、通过数、失败或超时；未运行则明确注明>
- **面试复述**：<自己的语言解释一个机制或失败边界>
- **项目归属说明**：独立实验结果不自动归入 Flashback/RAG 项目经历
- **48h / 168h 间隔复测题（闭卷）**：
  - 第 1 轮建议复测日期 (48h)：`YYYY-MM-DD`
  - 第 2 轮建议复测日期 (168h)：`YYYY-MM-DD`
  - 题目 1（机制）：<脱稿解释当前机制>
  - 题目 2（手写）：<闭卷完成一个最小变种>
  - 复测状态：待复测
- **下次启动第一步**：<一个 5 分钟内可以开始的动作>
```

不同题目的复测结果可用题目末尾的 `[第1轮已通过]` / `[已完全掌握]` 表示；整卡状态只在两题均达到该阶段时更新。执行验收通过不等于复测已通过。
